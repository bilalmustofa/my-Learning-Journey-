📝 Note Store Website

A simple and user-friendly web application that allows users to create, manage, and organize their personal notes in one place.

📌 About the Project

The Note Store Website is a personal note management application designed to help users keep track of their thoughts, ideas, reminders, and important information.

Each user can create and manage their own notes, making it easier to store and access personal information whenever needed.

✨ Features

Create Notes: Create and save personal notes.

View Notes: View all your saved notes.

Edit Notes: Update existing notes whenever needed.

Delete Notes: Remove notes that are no longer needed.

Personal Note Management: Manage your own notes independently.
