# The Rise of AI-Powered Applications

These Topic focuses on how AI is being integrated into traditional software applications and how developers can use AI models, APIs, developer tools, and AI coding assistants to build smarter applications.

## Traditional vs AI-Powered Applications

 * Traditional applications:

- Use rules written directly by developers
- Usually produce predictable results
- Work well for exact workflows
- Examples: forms, payments, CRUD applications, permissions

 * AI-powered applications:

- Combine traditional application logic with model intelligence
- Can understand meaning and similarity
- Can generate content
- Can make predictions and provide personalization
- May produce probabilistic rather than completely deterministic results

The main idea is that AI does not replace the application. Instead, it adds an intelligence layer to the existing software.

## Why AI Apps Are Emerging Now

There are three (3) major reasons: model-as-a-service APIs, faster hardware, and better developer tools.
 * Model-as-a-Service (APIs): 
   Developers no longer need to train huge AI models themselves.  Instead, we use simple APIs: we send a text request (like a user prompt) over the internet and receive a text response from the AI. 
* The Hardware Explosion (GPUs): 
  GPUs can perform many calculations in parallel, making large-scale AI   training and inference much more practical. Without this hardware progress, modern AI apps would be too slow or too expensive to use in real time.
* Developer Tooling:
  New tools make it easier for developers to build AI applications.
